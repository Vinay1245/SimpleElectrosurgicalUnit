# SimpleElectrosurgicalUnit
I created a really simple electrosurgical unit. Here are the functions:\
Button 1 = Turn the device on Standby or Treatment. On treatment, the Green LED turns on.\
Button 2 = Cycle between the treatments, which are Cut, Fuluragtion, and Blend\
Button 3 = When on a specific treatment mode, a buzzer plays a certain frequency. Will not play anything on Standby mode.
